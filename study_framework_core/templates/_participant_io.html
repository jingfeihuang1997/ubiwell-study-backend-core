Export data

Range
The ZIP holds: participant.json (profile and clinical info, every check-in with its questions and answers, questionnaires, sleep estimates; the file Import reads), checkins.csv (one row per answer), results.csv, sleep_estimates.csv, raw watch and phone readings as CSV, and a README explaining every column. Times are UTC. Never included: app and Garmin passwords, encryption keys, web login details.

Import data

The ZIP from Export, or its participant.json. Adds profile fields, check-ins and questionnaires; a check-in already here is replaced only by a newer copy of it. Watch data is not imported: it only comes from the app.
